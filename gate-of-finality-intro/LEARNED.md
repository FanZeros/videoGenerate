## 必须改的习惯
1. 拼图分镜不能当视频参考图。视频只吃完整16:9关键帧。
2. 每镜一个主运镜，不要堆dolly+pan+zoom。
3. 30秒按时间轴写：0-7s / 7-13s / 13-21s / 21-30s。
4. 每镜必须做三件事之一：改情绪 / 推进动作 / 加压。漂亮空镜删掉。
5. 30秒节拍：Hook -> Pressure -> Crack -> Impact -> Aftermath。不能跳过Crack。
6. 提示词用完整电影句子，不要堆cinematic 8k masterpiece。
7. 画面禁编号禁字幕。Seedance用 no captions。
8. 图生视频要写清参考图职责：@Image1 = 城，@Image2 = 门，@Image3 = 四人，@Image4 = 桌。
